# ShadowFox Java Projects

A collection of functional, console-based Java applications focused on core object-oriented programming concepts, data management, and algorithmic logic.

---

## 📂 Included Projects

### 1. Contact Management System (`ContactManagementSystem.java`)
A complete console application designed to manage personal or professional contacts. 
* **Key Features:** Allows users to add new contacts, view existing lists, search for specific entries, and update or delete records.
* **Concepts Used:** Object-Oriented Programming (OOP), ArrayLists/Collections for data storage, and structured user input handling.

### 2. Enhanced Calculator (`EnhancedCalculator.java`)
A robust command-line calculator that expands beyond basic arithmetic.
* **Key Features:** Supports standard operations (addition, subtraction, multiplication, division) alongside advanced mathematical functions like exponents, roots, or basic memory controls. Includes robust error handling to prevent division-by-zero crashes.
* **Concepts Used:** Control flow logic, mathematical functions, and input validation.

---

## 🚀 How to Run the Files

To run any of these applications locally, ensure you have the Java Development Kit (JDK) installed, then execute the following commands in your terminal:

```bash
# Compile the desired project
javac ContactManagementSystem.java

# Run the application
java ContactManagementSystem
